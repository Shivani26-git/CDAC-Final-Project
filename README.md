#  Blindness Detection Using PyTorch

This project focuses on detecting blindness from medical images using deep learning with PyTorch. The model classifies input images and assists medical professionals in identifying signs of blindness accurately and efficiently.

---

##  Features

- Image Preprocessing: Automatically resizes images to 256x256 pixels.
- Custom PyTorch Model: Deep learning model built using PyTorch.
- Training & Validation: Tracks and prints loss after each epoch.
- Model Saving: Saves the trained model for future predictions.
- Visual Insights: Graphical visualization of loss across epochs.

---

##  Model Output:

Prints training and validation loss after each epoch.
Visualizes the training and validation loss using graphs.

##  Model Evaluation:
 
Loss Graphs: Visual representation of loss reduction across epochs.
Accuracy Metrics: Displays the model's accuracy during validation.

## Technologies Used:
Python 3.x
PyTorch - Deep learning framework
